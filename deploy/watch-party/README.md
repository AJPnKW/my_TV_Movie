# Watch Party Hosted Service

This Compose stack runs the reusable watch-party room server in an isolated Docker container.

Services:
- `watch-party`: Node WebSocket/API room-sync server on port `8789`.
- `watch-party-tunnel`: Cloudflare quick tunnel that gives the server a public HTTPS/WSS endpoint for proof-of-concept internet testing.

The quick tunnel URL is generated by Cloudflare at runtime. For a permanent production endpoint, replace the quick tunnel with a named Cloudflare Tunnel, Caddy/Nginx with a real DNS name, or another HTTPS reverse proxy.

Local deploy target:

```sh
cd /srv/my_tv_movie/watch-party
docker compose up -d --build
docker logs my-tv-movie-watch-party-tunnel
```

The GitHub Pages client must set `window.MyTvMovieWatchPartyServerUrl` or pass `serverUrl` to `MyTvMovieWatchPartyPlayer.init()` with the public HTTPS endpoint.
