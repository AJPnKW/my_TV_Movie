Every Codex prompt must begin with a session header:

DO NOT CROSS INTO: IPTV_Manager_Hybrid, unrelated media renamer-only work, or non-my_TV_Movie threads

4. Parallel work rule

  • Do not run two Codex sessions against the same files unless one is explicitly read-only or documentation-only.
  • If parallel sessions are unavoidable, each session must list owned files and forbidden files.
  • At completion, every session must return: session code, objective, commits, files changed, validation, remaining blockers, and whether another session must pull/rebase.
  • Before applying another Codex output, run git pull origin main in the active shell and confirm clean status.
