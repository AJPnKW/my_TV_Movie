## Section 5.6 — Person Popup (Removed)

### Status
**Removed / Deprecated.**  
This popup is not part of the intended UI, workflow, or feature set for My TV Hub.

### Reason for Removal
- The Person Popup was never part of the core product vision.
- No UI views, data models, or workflows depend on it.
- No user stories or functional requirements reference it.
- Its inclusion would introduce unnecessary complexity and scope creep.

### Implementation Requirements
- **Do not implement** a Person Popup.
- **Do not reference** a Person Popup in UI, routing, metadata, or scripts.
- **Do not create** any assets, templates, or handlers related to this popup.
- **Do not include** this popup in future‑phase planning unless explicitly reintroduced.

### Versioning Note
- Deprecated as of **Spec Version X.Y** (update with your current version).
- Retained in the spec **only to preserve numbering stability** and avoid breaking cross‑references.
