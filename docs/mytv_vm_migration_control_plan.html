4. Required capabilities that GitHub Pages cannot properly handle

  • Reliable write/update of watched status, watchlist, and favourites.
  • Two-way sync with Trakt/commercial APIs using secrets and token refresh.
  • PostgreSQL persistence and audit history.
  • Media file inventory and file repair/remux.
  • Local WD TV Live/media device path discovery from home/trailer networks.
  • Server-side validation, scheduled jobs, and logs.

Every session must update documentation before returning success. Documentation must capture:

  • what user said in narrative form
  • what was interpreted as the technical requirement
  • architecture decision
  • files changed
  • validation evidence
  • remaining risks
  • next owner/session
