# Show Popup Contract

- Model after the Heated Rivalry direction: dense metadata, strong two-column hero, plain fact rows, season rail, episode rail.
- Popup header close control is an `Exit` action and receives focus first for D-pad use.
- Series facts are rendered as clean key/value rows, not bubble cards.
- Where-to-watch must not sit as a separate section between the season band and the episode rail.
- Provider availability stays in the fact rows and action model instead of creating a redundant middle block.
- Season selector remains horizontal and must support left/right jump buttons.
- Season navigator and selected-season detail are one continuous season band, not two disconnected surfaces.
- Selected season detail must include:
  - season name
  - episode count
  - premiere date
  - last available episode date when present
  - season description
- Episode section inside popup is a horizontal carousel using the shared episode card contract.
