Discover Decision

Do not treat Discover as deferred. The user intent is a real discovery surface similar to Trakt Discover, rendered in the current app style, and fed by content outside the local watched/watching catalog.

  • Discovery source should be separate from local library selection.
  • Suggested items should be excluded when they are already watched, watching, watchlisted, or otherwise locally known, unless the page explicitly explains why they remain visible.
  • Do not collapse Discover into Dashboard recommendations; they solve different jobs.
  • If the feed source is not yet documented, that is a documentation gap, not a reason to mark the route inactive.

Coordinator Rules for ChatGPT

  1. Use the master contract as the active source of truth.
  2. Use the archive only as evidence for recovered concepts or unresolved decisions.
  3. Use extraction files to avoid duplicating already captured findings.
  4. Do not rewrite active contract language into a generic summary if the archive preserved a sharper rule.
  5. When a page role is unclear, record the gap explicitly instead of guessing a behavior.
  6. Prefer one canonical page per role. If two pages remain, their separation must be documented and enforced.
