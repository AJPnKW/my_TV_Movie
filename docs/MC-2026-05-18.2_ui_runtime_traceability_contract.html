7. Media Library and WD TV Live design

  • web/Media_Library.html must exist and be linked only from the top nav row.
  • Media Library supports local-media access workflows from home and trailer networks.
  • Home network profile: 192.168.1.x. Trailer network profile: 192.168.2.x.
  • The goal is to use local device/media access where possible to reduce WAN and trailer Wi-Fi load.
  • Media Library maps catalog item → expected filename → actual media file path → QA result → repair/remux result → playable status.
  • Status buckets: OK, repaired, needs review, quarantined, duplicate, unsupported.

8. Required validation rules

  • Fail if provider URL is visible as text in Providers section.
  • Fail if provider rows are stacked as name + URL blocks instead of country-row layout.
  • Fail if provider anchors render as outlined buttons/cards.
  • Fail if generated filename copy text excludes date or TMDB ID.
  • Fail if displayed copy value differs from copied value.
  • Fail if episode card lacks TMDB ID.
  • Fail if Calendar and Dashboard use divergent episode-card markup.
  • Fail if Media Library icon appears outside .nav.
  • Fail if Light mode still creates image src attributes for suppressed images.
  • Fail if media QA pipeline lacks ffprobe or ffmpeg stream-copy remux verification.
  • Fail if docs/00_master_contract.html does not include or link this MC-2026-05-18.2 detail contract.
