Master Contract Change-Control Amendment

Mandatory Rule

The master contract must never be regenerated from scratch. It must be modified from the current committed version and every change must add a version/change-control record.

Required Contract Tabs/Sections

SectionPurpose
Version HistoryRecord version, date, source pass, author/agent, changed sections, reason, validation evidence
Source Extraction RegisterList each old source doc reviewed, status, extracted requirements, deprecated content, unresolved decisions
Active ContractCurrent authoritative design, architecture, UI, data, assets, workflow, validation
Deprecated/Legacy AppendixReference removed designs and legacy code names so future reviews can identify drift
Open DecisionsExplicit decisions not yet finalized, with owner and next action
