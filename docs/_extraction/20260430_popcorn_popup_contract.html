Deterministic Popcorn Popup Contract

Status

This supplement is active extraction evidence for the next master-contract update. It aligns with the code change in web/js/action_bar.js commit 70d291596f8e2fa0c80334332c7ffd9a5d02a1ad.

Contract

RuleRequirement
Click behaviorClicking 🍿 always opens the provider popup immediately.
Resolution orderOpen popup first; resolve movie/show/episode/source data second.
Missing dataMissing IDs or sources must not prevent the popup from opening. Show a fallback message and TMDB provider link when possible.
Owneraction_bar.js owns normalized popcorn attributes. Runtime popup code opens and resolves only.
Required base attributesAll rendered 🍿 buttons must include data-popcorn-action="open-provider-popup", data-popcorn-contract="open-first", and data-kind.
Movie identitydata-kind="movie", data-id, data-movie-id.
Episode identitydata-kind="episode", data-show-id, data-season, data-episode.
Show identitydata-kind="tv", data-id, data-show-id.
ForbiddenNo page-specific popcorn handlers. No fragile card-specific click logic. No silent failure.

Validation Requirement

  • Every rendered 🍿 opens the popup immediately.
  • Every rendered 🍿 includes normalized base attributes.
  • Movie, episode, and show identities are present where source data exists.
  • Missing data produces fallback content, not no-op behavior.
