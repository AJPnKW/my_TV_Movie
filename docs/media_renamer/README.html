Media Cleanup Pipeline

This tool is now a two-step home-user pipeline. It is not a complex review app. The user builds a cleanup plan, then applies safe changes.

Final folder rule

Run commands

Set-Location -LiteralPath "C:\Users\andrew\PROJECTS\GitHub\my_TV_Movie"
powershell -ExecutionPolicy Bypass -File scripts\validate_media_cleanup_pipeline.ps1
powershell -ExecutionPolicy Bypass -File scripts\run_media_cleanup_plan.ps1
powershell -ExecutionPolicy Bypass -File scripts\apply_media_cleanup_plan.ps1
powershell -ExecutionPolicy Bypass -File scripts\run_media_cleanup_plan.ps1

What plan mode does

  • Scans C:\X1_Share\Recordings.
  • Includes loose root files, TV, Movies/movies, _Unsorted, ShowA, ShowB, and any old Shows folder.
  • Builds a plan only. It does not move files.
  • Creates reports under reports\media_renamer\timestamp.

What apply mode does

  • Moves only safe planned TV and Movie matches.
  • Moves duplicate losers to _MediaRenamer_Duplicates.
  • Moves zero-byte files to _MediaRenamer_Quarantine.
  • Moves lowercase movies content into Movies.
  • Removes ShowA, ShowB, and Shows only if empty.

Safe match rule

A file is safe when the repo catalog identifies the media item and confidence is at least 85. TV files require TMDb show identity plus season and episode. Movie files require TMDb movie identity.

Problem files

Problem files are left alone and listed in problem_files.csv. Reasons include no catalog match, confidence below 85, unlinked sidecar, extensionless file not proven, or unresolved duplicate tie.
