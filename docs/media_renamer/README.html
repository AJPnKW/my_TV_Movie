Media Cleanup Hub Runbook

Normal user workflow

  1. Run powershell -ExecutionPolicy Bypass -File scripts\run_media_cleanup_launcher.ps1.
  2. Click Clean Recordings Now.
  3. Open Media Library when the run completes.

What the cleanup does

The cleanup pipeline normalizes recordings under C:\X1_Share\Recordings. Safe matches are fixed automatically. Problem files are left alone and reported. Nothing is silently deleted.

Final folderPurpose
TVNormalized show folders, season folders, episode files.
MoviesNormalized movie folders and movie files.

Media library page

The generator creates C:\X1_Share\Recordings\Media_Library.html and C:\X1_Share\Recordings\Media_Library.json. The page includes show/movie title, TMDb ID, release or air date, runtime, genres, status, S##E##, episode name, file path, and file size.

Direct commands

powershell -ExecutionPolicy Bypass -File scripts\run_media_cleanup_full_cycle.ps1
powershell -ExecutionPolicy Bypass -File scripts\generate_media_library_page.ps1
powershell -ExecutionPolicy Bypass -File scripts\validate_media_library_page.ps1

Failure messages

If a run fails, the GUI shows an Open Log button and a clickable link to the run log. Use the support ZIP from .ai_uploads for troubleshooting.
