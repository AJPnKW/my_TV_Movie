Media Cleanup Design Record

Version: v0.6.8

Single pipeline contract

1. Build naming cleanup plan.
2. Apply safe naming cleanup.
3. Repeat until no safe actions remain.
4. QA every TV/Movie media file with ffprobe.
5. Repair files needing repair with ffmpeg.
6. Regenerate Media_Library.html and JSON.
7. Produce logs/reports.

Correct final folders

C:\X1_Share\Recordings\TV
C:\X1_Share\Recordings\Movies

Script quality rules

RuleReason
No Invoke-NativeProcess helper.It repeatedly failed due null method calls.
No $Args assignment or @Args splatting.$Args is a PowerShell automatic variable and caused Python to run without arguments.
No ProcessStartInfo.ArgumentList.Add.Not safe across Windows PowerShell 5.1/.NET variants.
Use Start-Process with quoted .Arguments and separate stdout/stderr files.Prevents NativeCommandError and redirect conflicts.

Primary command

powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_media_cleanup_integrated.ps1
