Library page layout

  • Single compact top bar.
  • TV show row is one line: title, TMDb, seasons, episode count, new 7d, new 14d, genres.
  • Clicking a show expands all seasons and all episode rows in one action.
  • Episode rows include S##E##, title, air date, runtime, file size, HTTP, Copy HTTP, Copy UNC, and Copy SMB.
  • Show row intentionally excludes first air date, status, and default runtime to keep the layout compact.
