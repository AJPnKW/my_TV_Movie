Media Cleanup Implementation Record

Version: v0.5.1

Purpose: normalize C:\X1_Share\Recordings into TV and Movies, then generate a production-quality HTML title page for the normalized recordings.

User Workflow

ButtonActionResult
Clean Recordings NowValidate, build plan, apply safe actions, repeat until no safe actions remain, generate media library page, create support ZIP.One user action for routine cleanup.

Failure handling

The GUI failure dialog now includes the exact log path and an Open Log button. The main screen also shows clickable links to the run log, latest report, support ZIP, and media library page when available.
