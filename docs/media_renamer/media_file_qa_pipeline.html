Media File QA Pipeline

Version: v0.6.8

Required integrated flow

Plan/apply naming cleanup → ffprobe QA for all TV/Movie files → repair flagged files → regenerate Media_Library.html

Scope

All media files under C:\X1_Share\Recordings\TV and C:\X1_Share\Recordings\Movies are in scope. The two Your Friends & Neighbors files are examples only, not the scope limit.

QA criteria

CheckRule
Readableffprobe must parse format and streams.
VideoVideo stream must exist and duration must be above zero.
ContainerMP4 is preferred for Android/Chromecast/browser playback.
CodecH.264/H.265 video and AAC/MP3/AC3/EAC3 audio are treated as TV-safe enough.
RepairRemux to MP4 faststart first; transcode to H.264/AAC only if remux fails.
SafetyOriginal files are backed up before replacement under _MediaRenamer_Originals\timestamp.

Commands

powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_media_cleanup_integrated.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\qa_media_playback.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\repair_media_playback.ps1
