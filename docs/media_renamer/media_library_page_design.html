Media Library Page Design Record

Version v0.6.1 generates a compact local title page at C:\X1_Share\Recordings\Media_Library.html.

RequirementImplementation
Condensed layoutOne-line show rows using a flex layout; no large cards; no show-row first-air-date/runtime fields.
Show-level new-release indicatorsEach show row includes green new 7d and blue new 14d badges calculated from TMDb episode air dates.
Single-click expandClicking a show expands/collapses all seasons and episodes for that show at once.
PerformanceThe generator loads only catalog detail JSON files referenced by local TV/Movie folder TMDb IDs instead of parsing every catalog detail file.
Metadata retainedEpisode rows include S##E##, episode title, air date, runtime, size, and file name. Movie rows include release date, runtime, status, genres, size, and file name.
User app workflowThe GUI uses a fast cleanup cycle for normal use and has a separate Generate Media Library action.

v0.6.1 QA correction

Released is valid movie/show metadata and is no longer treated as an old layout marker. Forbidden layout checks remain focused on structural markers such as stat-card, card-grid, large-stat, First , and show-line.
