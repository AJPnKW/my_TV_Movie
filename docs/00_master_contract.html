3.1 Header and Navigation

  • Header contains Boys logo, icon-only primary nav, Ready/version status.
  • Primary nav icons are standalone Unicode/web icons, not boxed buttons.
  • Icons must be large and clickable across desktop, partial desktop, tablet, and phone.
  • Logo must preserve aspect ratio and must not stretch into a banner.
  • Header is compact and sticky.
  • Ready/version must not collide with nav.

4. Calendar Contract

  • Calendar month grid must remain a seven-column Mon-Sun wall/grid on desktop/tablet.
  • Do not collapse calendar into stacked cards except on true mobile.
  • Sticky calendar control bar and sticky weekday row are required.
  • Dashboard and Calendar share +X more / expand behavior. No silent truncation.
  • Calendar list mode is allowed but must not replace the grid contract.

5. Watch State and Manage Watch State

StateMeaningControl
watch_listQueued/intended to watch.Two-state compact switch.
favouriteLike/recommendation signal.Two-state compact switch.
watched_statusunwatched / partially watched / watched.Three-state segmented switch if supported; local tri-state if Trakt mapping is limited.

Manage Watch State layout

  • Standalone route: web/manage_watch_state.html.
  • Lean table/matrix with tree hierarchy: show → season → episode; movies as single rows.
  • Not a media detail page.
  • Column headers define state fields; row controls are compact switches, not large named buttons.
  • Filters: type, watch_list, watched_status, favourite, Trakt mismatch, missing ID, queued update, unreleased blocked.
  • Bulk actions are allowed only where safe.
<state_type>:movie:<tmdb_id>
<state_type>:show:<tmdb_id>
<state_type>:season:<show_id>:<season_number>
<state_type>:episode:<show_id>:<season_number>:<episode_number>
  • Unreleased movies/episodes cannot be marked watched.
  • Season/show rollups derive from released eligible episodes.

6. Discover Contract

Discover is active and distinct from Dashboard recommendations.

  • Discover is fed by external/non-local discovery sources, not only the local catalog.
  • Required feed registry: source name, source type, normalization script/data, refresh cadence, ID fields, exclusion rules.
  • Exclude items already watched, watching, watchlisted, favourited, or otherwise locally known unless explicitly labelled as re-surfaced.
  • Discover must not duplicate Dashboard recommendations.
  • If no feed is configured, page must show a clear empty/config-needed state, not fallback to local duplicates.
