9. Media File QA and Repair Pipeline

Added: MC-2026-05-09.2 | Updated: MC-2026-05-09.2 | Origin: media renamer drifted into naming-only instead of full file QA

This is part of the single media cleanup pipeline. It applies to all media files, not just examples.

scan → identify → filename match → ffprobe QA → classify → repair/remux if safe → rename/move → final validation → report
StageRequirement
ScanProcess all supported media files under selected input folders.
Filename matchMatch against repo catalog data and media rules.
ffprobe QAValidate container readable, duration present, video stream where expected, audio stream where expected, codec readable, not zero-byte, not truncated/incomplete where detectable, extension/container consistency.
Compatibility targetOutput must work in VLC and X-plore.
Repair/remuxIf readable but poorly packaged, repair using ffmpeg stream copy before rename/move.
QuarantineIf repair fails or file is unsafe to repair, quarantine and report. Never silently skip.
Reportsmedia_file_qa.csv, media_file_qa.json, repair_actions.log.txt, unrepaired_files.csv, final_summary.html.
