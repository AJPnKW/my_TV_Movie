5.4 provider_popup_guard.js Rule

web/js/provider_popup_guard.js is a guard, not a renderer. It may post-process the existing popup DOM only. It must never generate a replacement minimal popup unless the runtime popup shell is completely missing and even then must preserve all available media metadata.

StatusRender behaviorMeaning

8. Media File QA / Cleanup Pipeline

Added: MC-2026-05-09.1. Origin: media renamer drift: filename cleanup existed but full media-file QA/repair was not enforced as part of the single pipeline.

scan → identify → filename match → ffprobe QA → classify → repair/remux if safe → rename/move → final validation → report
StageRequirement
ScanAll media files under selected input root are included. Examples are not scope limits.
ffprobe QACheck container readable, duration, video/audio streams, codec readability, zero-byte/truncated errors, extension/container mismatch.
Compatibility targetFiles must be suitable for VLC and X-plore playback where practical.
Repair/remuxIf readable but poorly packaged, use ffmpeg stream copy remux before rename/move. Do not transcode unless explicitly designed.
QuarantineIf repair fails, quarantine and report. Never silently skip.
Reportsmedia_file_qa.csv, media_file_qa.json, repair_actions.log.txt, unrepaired_files.csv, final_summary.html.
