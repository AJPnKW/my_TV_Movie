Debug: data not showing
1. Check data.json
• Open /data/data.json
• Confirm "shows" and "movies" arrays have entries.

2. Validate input files
• One entry per line.
• TV: name|tmdb_show_id|season_spec|tvmaze_id(optional)
• Movies: name|tmdb_movie_id
• Lines starting with # are comments. No separator-only lines.

3. Check workflow
• Last run of Build TV Data and Deploy must be green.

4. Wiring sanity
• Workflow must call python scripts/fetch_tmdb.py from repo root.
• Script must read tv_list.txt and movies_list.txt in repo root.

5. UI cache
• If data.json has movies but Movies tab is empty, hard refresh / clear cache.
